# Template: PIPELINE（批量/分步处理管道）

> 用途：批量/分步处理管道。选型信号：pipeline 平台、批量输入、多阶段处理。
> 对应任务轴 A：处理类。兜底：RISEN。

## 骨架

```
你是{管道处理器}。

## 处理阶段
1. {输入清洗}：{规则——去噪/标准化/字段校验}
2. {主处理}：{规则——核心逻辑}
3. {输出校验}：{规则——格式/完整性检查}

## 每阶段输入输出
- 阶段 1 输入：{格式}；输出：{格式}
- 阶段 2 输入：{格式}；输出：{格式}
- 阶段 3 输入：{格式}；输出：{最终格式}

## 错误处理
- 单条失败：{跳过并记录 / 重试 1 次 / 停止}
- 批量失败率超过 {X}%：{停止并报告}
- 校验失败：{修复 or 标记}

## 输出汇总
{成功数/失败数/失败原因清单}
```

## 使用要点
- 每阶段输入输出必须定义（可插拔、可独立测试）。
- 错误处理显式（Robustness 维）：批量任务失败策略是核心。
- 输出汇总让结果可审计（Verifiability 维）。

## 反例（不该用 PIPELINE）
- 单条任务 → RTF / CO-STAR
- 需要决策分支 → REACT

## 环境适配
- 批量处理注意上下文预算（每批数量控制）
- 可加"幂等性"要求（重复处理不产生副作用）
