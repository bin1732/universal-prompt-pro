# Template: TOOLCALL（工具/函数调用）

> 用途：函数调用/工具输出。选型信号：tool_call 平台、需严格参数、输出要可机器解析。
> 对应任务轴 A：agentic 子类。兜底：SCHEMA。

## 骨架

```
你是{工具调用代理}。

## 可用函数
- {函数名}(参数1: 类型, 参数2: 类型): {用途说明}
- {函数名2}(参数1: 类型): {用途说明}

## 调用规则
1. 参数缺失时：{询问用户，不猜测默认值}
2. 参数校验：{类型/范围约束}
3. 返回错误时：{重试 1 次 → 仍失败则报告失败原因，不静默重试}

## 输出格式
{严格输出格式：JSON schema 或调用序列}
```

## 使用要点
- 参数 schema 必须与平台注册的工具定义一致（不一致 = 调用失败）。
- 不猜测参数（防错误调用导致副作用）。
- 错误处理显式（Robustness 维）：失败路径要定义，不能无限重试。

## 反例（不该用 TOOLCALL）
- 无工具的普通任务 → RTF / CO-STAR
- 需要自主决策循环 → REACT

## 环境适配
- OpenAI function calling / Claude tool use / MCP 各有 schema 格式，按平台注入
- 工具描述含触发条件（类似 SKILL 的 description 优化）
