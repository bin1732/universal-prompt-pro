# Template: REACT（Reasoning + Acting，含停止条件）

> 用途：自主代理（agentic）任务，需要工具循环。选型信号：自主代理、需要工具调用。
> 对应任务轴 A：agentic。兜底：RISEN。

## 骨架

```
你是一个{自主代理角色}。
可用工具：
- {工具1}: {用途}。参数: {schema 或描述}
- {工具2}: {用途}

工作循环：
1. 思考（Reasoning）：分析当前状态，决定下一步
2. 行动（Action）：调用一个工具（如需要）
3. 观察（Observation）：读取工具结果
4. 重复直到满足停止条件

停止条件（必须显式）：
- 当{完成标准}达成时，输出最终结果并停止
- 当工具连续失败 {N} 次时，停止并报告失败原因
- 当无法确定时，请求用户确认，不要擅自猜测

权限边界：
- 只允许调用：{白名单}
- 禁止：{黑名单，如删除/覆盖/付费操作}

自检（每次行动前）：
- 本次行动是否在权限白名单内？
- 是否存在更安全的替代？
```

## 使用要点
- 停止条件是 agentic 提示词的灵魂（无停止条件 = 无限循环）。
- 权限边界必须有白名单 + 黑名单（越权防护）。
- 自检步骤是 Verifiability 维的加分项。

## 反例（不该用 REACT）
- 无工具的单步任务 → RTF
- 只需顺序执行无需决策 → RISEN
- 纯推理 → COT

## 环境适配
- Claude Code / GPT Codex / OpenClaw 各有工具语法，需按平台注入实际工具描述
- 高风险动作必须人工确认（OWASP 建议 5）
