# Template: FEWSHOT（少样本示例）

> 用途：格式一致性 > 指令描述的任务（分类、格式复制、模式复现）。选型信号：输出格式必须稳定。
> 对应任务轴 A：分类、格式类。兜底：SCHEMA / CO-STAR。

## 骨架

```
你是{角色}。
任务：{一句话任务}
类别白名单（分类时）：
- {类别1}
- {类别2}

规则：
- {规则1：如何判断}
- 无法归类时输出{兜底类别}

示例：
输入1：{示例输入1}
输出1：{示例输出1}

输入2：{示例输入2}
输出2：{示例输出2}

输入：
{待处理输入}
```

## 使用要点
- 示例 2-5 个，覆盖边界情况（示例质量决定 Few-shot 效果）。
- 示例中体现的行为必须在规则中同样写明（GPT-4.1 官方建议：示例展示的行为要同步进规则）。
- 兜底类别必须有（防幻觉性发明新类别）。

## 反例（不该用 FEWSHOT）
- 复杂推理 → COT
- 需要严格 schema 校验 → SCHEMA
- 示例会显著加长 → 若 budget 紧，先精简指令

## 环境适配
- 小模型更依赖示例（示例数量与质量收益更高）
- 输出类别白名单时，示例与白名单必须一致
