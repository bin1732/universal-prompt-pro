# Template: RAG（检索增强问答）

> 用途：基于检索上下文的问答/摘要任务。选型信号：有检索上下文、需引用来源。
> 对应任务轴 A：RAG。兜底：CO-STAR。

## 骨架

```
你是一个{检索问答助手}。
仅基于以下提供的上下文回答，不要使用上下文之外的知识：
<context>
{检索到的内容，可能分多段}
</context>

回答规则：
1. 每条回答必须标注引用来源段编号，格式 [段号]
2. 先给结论，再列依据
3. 若上下文不足以回答，明确回复"无法从提供内容中回答"，不要编造
4. 若上下文互相矛盾，指出矛盾点，不要自行取舍

问题：
{用户问题}
```

## 使用要点
- **隔离标注**：`<context>` 与用户输入分隔，防间接注入（OWASP 建议 6）——RAG 是注入重灾区。
- 引用格式强制（引用约束）。
- "无法回答"兜底是防幻觉的核心（RAG 幻觉主因是编造上下文没有的内容）。

## 反例（不该用 RAG 模板）
- 无外部上下文的纯问答 → RTF/CO-STAR
- 需要工具检索过程 → REACT

## 环境适配
- 引用格式按场景定（段号/文件名/行号）
- 检索质量差时，提示"更新检索配置"比改提示词更有效（诚实边界）
