# references/techniques.md — 技术目录与禁用清单

> 用途：L3 技术选择。**只采用有可靠边界效应的技术；禁用依据不足或效果不可控的技术（防伪科学，P5）。**

## 可靠技术（可选用）

| 技术 | 何时用 | 边界效应 |
|------|--------|----------|
| 角色设定 | 校准深度与措辞 | 一致性好 |
| Few-shot | 格式一致性 > 指令 | 稳定复现 |
| XML/Markdown 结构标签 | 结构可解析的宿主 | Claude 解析可靠 |
| 防幻觉锚点 | 事实/引用任务 | 减少捏造 |
| CoT | 推理任务（**非 o 系**） | 多步准确率提升 |
| 记忆块（Memory Block） | 长会话 | 防自相矛盾 |
| 拒绝话术 | 不确定/越界输入 | 降低幻觉式应答 |
| 隔离标注 | 含外部输入内容 | 防间接注入（OWASP 建议 6） |

## 禁用清单（不推荐、不产出）

| 技术 | 禁用理由 |
|------|----------|
| Tree-of-Thought | 依据不足、效果不可控 |
| Graph-of-Thought | 同上 |
| 通用自洽（Self-Consistency 全量） | 成本高、收益不确定 |
| 无锚 prompt chaining | 链断即全断，无兜底 |
| 情感操纵/小费诱骗（"你一定会做好的，给 $200"） | 无实证收益，且 OpenAI 官方建议不用 |
