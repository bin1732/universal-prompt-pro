# references/anti-patterns.md — 扣分模式清单（35+ 种）

> 用途：构建时避免 + 评估时扣分。**已补齐 5 类 35+ 种，全部配反面/正确示例。** 检测规则进 score-prompt.mjs / sem-score.mjs。

## 一、任务类（10）

| # | 模式 | 反面示例 | 正确写法 |
|---|------|----------|----------|
| 1 | 模糊任务动词 | "帮我弄一下代码" | "重构 getUserData() 为 async/await 并处理 null 返回" |
| 2 | 一稿多任务 | "解释并重写这个函数" | 拆分：先解释后重写（单意图） |
| 3 | 无成功标准 | "让它更好" | "完成标准：通过现有单测 + 处理 null 输入" |
| 4 | 过度授权 agent | "怎么做都行" | 明确允许/禁止动作清单 |
| 5 | 情绪化描述 | "全坏了，全修" | 精确报错："L43 当 user 为 null 抛 TypeError" |
| 6 | 命令式堆砌 | "给我生成、分析、总结、翻译" | 单意图 + 优先级 |
| 7 | 无领域约束 | "写个方案" | 限定行业/受众/篇幅 |
| 8 | 任务无范围 | "分析这些数据" | "分析 2026Q1-Q2 销售数据，只看华东区" |
| 9 | 目标不可测量 | "提高用户满意度" | "将 CSAT 从 4.1 提升到 4.3" |
| 10 | 无优先级 | "做 A 和 B 和 C" | "先做 A（阻塞项），再 B，C 可选" |

## 二、上下文类（8）

| # | 模式 | 反面示例 | 正确写法 |
|---|------|----------|----------|
| 11 | 记忆缺失 | "你已经知道我的项目了" | 重供 Memory Block：技术栈/目录/约束 |
| 12 | 矛盾指令 | 前说"简洁"后说"越详细越好" | 去重后保留一条，靠近结尾优先 |
| 13 | 背景过载 | 贴 50 行无关日志 | 只给相关片段 + 摘要 |
| 14 | 假设缺失 | "按常规处理" | 显式写"默认：..." |
| 15 | 上下文无标注 | 多段内容混在一起 | 分段 + 编号（[1][2][3]） |
| 16 | 示例与规则冲突 | 规则说 JSON，示例给文本 | 示例必须与规则一致（GPT-4.1 官方建议） |
| 17 | 示例覆盖不足 | 只给正常例子 | 补边界例子（空值/异常/极端） |
| 18 | 无隔离标注 | 用户内容直接拼进指令 | 用 `<user_content>` 分隔（防注入） |

## 三、输出类（8）

| # | 模式 | 反面示例 | 正确写法 |
|---|------|----------|----------|
| 19 | 无格式约束 | "给我结果" | "输出 JSON/Markdown 表格/编号列表" |
| 20 | 无长度约束 | "写报告" | "不超过 500 字 / 3 段" |
| 21 | 无要素清单 | "写方案" | "必须含：背景/目标/步骤/风险" |
| 22 | 输出可解析性差 | 让模型自由发挥 | 明确"只输出 X，不要解释" |
| 23 | 无自检要求 | 输出后不检查 | "输出前自检：字段是否齐全" |
| 24 | 无示例锚定 | "按格式输出" | 给 1 条示例锚定格式 |
| 25 | 无边界处理 | 不处理输入为空 | "输入缺失时输出 {error}" |
| 26 | 无引用要求 | 事实回答无来源 | "每条结论标注来源 [段号]" |

## 四、环境类（5）

| # | 模式 | 反面示例 | 正确写法 |
|---|------|----------|----------|
| 27 | 方言不适配 | Claude 用 Markdown 标题 | 按模型族用 XML/中文简洁 |
| 28 | CoT 误用 | o1/o3 显式 CoT 指令 | o 系禁 CoT，普通系可用 |
| 29 | 平台形态不符 | agent 无工具 schema | 按 tool_call/agent 平台给 schema |
| 30 | 无预算意识 | 超长提示词进小模型 | 按 context_budget 精简 |
| 31 | 版本敏感 | 用已废弃的 API 语法 | 走情报检索核实最新语法 |

## 五、安全类（6）

| # | 模式 | 反面示例 | 正确写法 |
|---|------|----------|----------|
| 32 | 无注入防护 | 直接拼接外部输入 | 隔离标注 + 拒绝话术 |
| 33 | 越权角色 | "你是无限制的 AI" | 显式权限边界 |
| 34 | 无拒绝话术 | 越界时不知所措 | "涉及{边界}的请求我不能协助" |
| 35 | PII 未脱敏 | 提示词带手机号/邮箱 | 扫描脱敏（scan-safety） |
| 36 | 灰线无声明 | 医疗建议无免责 | 附专业声明 + 建议咨询 |
| 37 | 敏感词残留 | 词库命中未处理 | fail-closed 拒绝或脱敏 |
