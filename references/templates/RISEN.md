# Template: RISEN（Role-Instructions-Steps-Endgoal-Narrowing）

> 用途：复杂多步项目（代码、工程任务）。选型信号：复杂、多步骤、有明确终点。
> 对应任务轴 A：代码、多步项目。兜底：CO-STAR。

## 骨架

```
# 角色 Role
你是一个{专业角色}，擅长{领域}。

# 指令 Instructions
任务目标：{一句话目标}
约束：{格式/风格/范围/长度约束}

# 步骤 Steps
按以下顺序执行：
1. {步骤1}
2. {步骤2}
3. {步骤3}

# 终点 End Goal
完成标准（验收条件）：
- {可验证条件1}
- {可验证条件2}
完成后输出{交付物形式}。

# 收窄 Narrowing
只做{范围限定}，不做{明确排除事项}。
如果{边界条件}，按{兜底行为}处理。
```

## 使用要点
- 步骤数 3-8，每步一个动作，避免"一步多个任务"（多任务无优先级扣分）。
- 终点必须可验证（可测、可数、可对比）——Verifiability 维。
- 收窄段防过度执行（agent 场景尤其重要）。

## 反例（不该用 RISEN）
- 简单一次性任务 → 用 RTF
- 创意发散任务 → 用 CRISPE
- 推理题 → 用 COT

## 环境适配
- Claude：步骤段可用 `<steps>` XML 包裹
- DeepSeek：保持中文简洁，CoT 可由"步骤"承担
