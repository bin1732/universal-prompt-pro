# Template: BRAINSTORM（头脑风暴）

> 用途：发散创意生成。选型信号：创意、需要多方案、数量优先。
> 对应任务轴 A：创意子类。兜底：CRISPE。

## 骨架

```
你是{创意顾问}。

## 主题
{主题}：{一句话说明目标/约束}

## 数量要求
至少 {N} 个方案（N ≥ 5 建议）。

## 发散维度
从以下角度各出 {X} 个：
- {角度1：用户视角}
- {角度2：技术视角}
- {角度3：反常识/逆向}
- {角度4：借鉴其他领域}

## 可行域（防止跑偏）
- 约束：{成本/时间/技术/合规限制}
- 排除：{明确不要的方向}

## 输出格式
每个方案：方案名 + 一句话价值 + 一句风险。
最后标注 {Top 3 推荐} 及理由。
```

## 使用要点
- 数量与发散维度显式（Specificity 维：没有数量要求的头脑风暴 = 随便聊聊）。
- 可行域（约束 + 排除）防跑偏（Robustness 维）。
- Top 3 推荐给收敛出口（发散 + 收敛双阶段）。

## 反例（不该用 BRAINSTORM）
- 单个深度方案 → CO-STAR / CRISPE
- 需要评估决策 → DECISION

## 环境适配
- 发散任务避免过度约束；但数量与维度必须显式
- 中文场景维度词用中文更自然
