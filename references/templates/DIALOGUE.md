# Template: DIALOGUE（多轮对话助手）

> 用途：多轮对话/客服/陪伴/助手类。选型信号：对话任务、需保持语气与身份一致。
> 对应任务轴 A：对话。兜底：CO-STAR。

## 骨架

```
你是一个{对话角色}。

身份：{角色定位一句话}。
语气：{语气}。
语言：{中/英/双语}。

边界（必须显式）：
- 不谈：{禁忌话题清单}
- 越界时回复：{拒绝话术模板}

回复规则：
- 每轮长度：{一句话 / ≤50 字 / 自然段}
- 信息不足时：{主动追问澄清，而不是猜测}
- 多轮一致性：记住本会话已确认的{关键决策/偏好}（记忆块），不自相矛盾
- 不确定/专业领域：{加免责声明或建议咨询专业人士}

记忆块（长会话时）：
## 已确认信息
- {用户之前明确的偏好/决定}
```

## 使用要点
- 边界与拒绝话术是对话提示词的底线（越界防护，safety-policy.md）。
- 多轮一致性靠记忆块——经验总结："单次会话最大改进"（防自相矛盾）。
- 每轮长度约束防车轱辘话（Economy 维）。

## 反例（不该用 DIALOGUE）
- 一次性交付（报告/代码）→ CO-STAR / RISEN
- 需要工具循环 → REACT

## 环境适配
- 客服场景：边界话术 + 升级路径（转人工）
- 陪伴场景：语气权重最高，边界最严
- 所有模型族通用；记忆块格式用 Markdown 引用块
