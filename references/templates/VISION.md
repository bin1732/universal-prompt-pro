# Template: VISION（视觉描述符）

> 用途：图像生成（Midjourney/DALL-E/SD/Sora/ComfyUI）。选型信号：图像生成任务。
> 对应任务轴 A：图像。兜底：RTF。

## 骨架（正向描述符，要素顺序即权重顺序）

```
{主体}，{动作/姿态}，{环境/背景}，{光线/氛围}，{构图/视角}，{风格}，{画质词}，{画幅比例}
```

**要素顺序规则**：图像模型对靠前 token 权重更高——主体最前，风格次之，细节靠后。

## 骨架（负向描述词——SD/ComfyUI 等支持时）

```
负面提示：{低质量}，{畸形}，{多余手指}，{水印}，{文字}
```

## 使用要点
- 风格词要具体（"赛博朋克 1980s" > "未来感"），避免抽象形容词（Specificity 维）。
- 画幅比例显式（16:9 / 1:1 / 9:16），不同工具语法不同（Midjourney 用 `--ar`，SD 用宽高）。
- 需要参考图编辑时：先描述"保持{元素}不变，改变{元素}"，再给参考图（检测编辑 vs 生成）。

## 反例（不该用 VISION）
- 文本任务 → CO-STAR 等文本模板
- 无图像需求的普通需求 → 走对应文本模板

## 环境适配（工具差异——关键节点走情报检索核实最新语法）
- Midjourney：`/imagine prompt: ... --ar 16:9 --v 6`（版本参数）
- DALL-E：自然语言描述 + size 参数（1024x1024 等）
- SD/ComfyUI：正向/负向分离，checkpoint 相关术语
- Sora：视频描述（运镜/时长/动态）
