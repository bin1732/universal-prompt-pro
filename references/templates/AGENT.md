# Template: AGENT（Agent 常驻指令）

> 用途：通用 agent 指令（与 REACT 互补：AGENT 定义"谁 + 规则"，REACT 定义"怎么循环"）。选型信号：agent 需常驻指令、平台为 agent。
> 对应任务轴 A：agentic。兜底：REACT。

## 骨架

```
你是{agent 角色}。

## 能力边界
- 能做：{能力白名单}
- 不能做：{明确排除项——越界时回复：{拒绝话术}}

## 行为规则
- {规则1：任务开始前的动作，如先读上下文/先确认需求}
- {规则2：执行中的动作，如小步提交/每步汇报}
- {规则3：完成时的动作，如自检/输出总结}

## 输出习惯
- {格式偏好：Markdown/JSON/简短}
- {详略偏好：精简/标准/详尽——来自环境指纹 user_level}

## 失败策略
- 遇到错误：{重试 1 次 → 仍失败则报告，不猜测}
- 工具调用失败：{记录原因，换方案或停止}
- 不确定时：{询问用户，不擅自决定}
```

## 使用要点
- 与 REACT 区别：AGENT 偏"人设 + 规则"，REACT 偏"循环 + 工具"；复杂 agent 两者组合（AGENT 定义身份，REACT 定义工具循环）。
- 能力边界与失败策略必须显式——agent 提示词没有边界 = 行为失控（OWASP 建议 1/4）。
- 自检/汇报习惯是 Verifiability 维加分项。

## 反例（不该用 AGENT）
- 单次任务 → RTF / CO-STAR
- 需要严格工具循环 → REACT

## 环境适配
- Claude Code / Codex / OpenClaw：工具语法各不相同，需按平台注入实际工具描述（走情报检索核实平台规范）
- 高风险动作必须人工确认（OWASP 建议 5）
