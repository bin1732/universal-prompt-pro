# Template: CLASSIFY（有限类别分类）

> 用途：有限类别分类。选型信号：类别明确、需稳定分类、格式一致性 > 指令。
> 对应任务轴 A：分类。兜底：FEWSHOT。

## 骨架

```
你是{分类器}。

## 类别白名单
- {类别1}：{定义/判定标准}
- {类别2}：{定义/判定标准}
- {兜底类别}：{无法归入以上类别时}

## 判断规则
- {规则1：关键特征 → 类别}
- {规则2：多类别冲突时取{优先级/主意图}}
- 无法自信分类时输出：{兜底类别}（不要发明新类别）

## 示例
输入1：{示例} → 输出1：{类别}
输入2：{示例} → 输出2：{类别}

## 输出格式
只输出类别名（或 JSON：{"category": "...", "confidence": 0.9}）
```

## 使用要点
- 白名单 + 兜底类别（防发明新类别——防幻觉）。
- 示例覆盖边界情况（Few-shot 质量决定分类稳定性）。
- 类别定义写清"什么算、什么不算"（Specificity 维）。

## 反例（不该用 CLASSIFY）
- 开放输出 → CO-STAR
- 需严格 schema → SCHEMA

## 环境适配
- 类别少（≤10）且边界清晰时，Few-shot 最稳
- 输出 JSON 时给 schema（tool_call 平台可直接绑定）
