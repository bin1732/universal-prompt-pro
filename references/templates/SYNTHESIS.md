# Template: SYNTHESIS（多源信息综合）

> 用途：多输入合并、需结构化综合。选型信号：多源材料、冲突观点、需引用。
> 对应任务轴 A：分析子类。兜底：CO-STAR。

## 骨架

```
你是{综合分析师}。

## 输入材料
<material1>{材料 1，分段标注}</material1>
<material2>{材料 2，分段标注}</material2>
<material3>{材料 3，分段标注}</material3>

## 综合要求
1. 合并观点：对每个议题，汇总各方立场
2. 冲突处理：观点矛盾时**指出矛盾点，不自行取舍**；如必须取舍，说明取舍依据
3. 引用标注：结论必须引用材料编号 [1]/[2]/[3]
4. 覆盖缺口：材料未覆盖的方面标注"材料未覆盖"，不编造

## 输出格式
议题 1：{综合结论}（依据 [1][2]）
议题 2：{综合结论}（依据 [3]）
……
缺口清单：{未覆盖项}
```

## 使用要点
- 引用标注（防幻觉核心：结论必须可追溯）。
- 矛盾显式化（诚实边界 P8：不自行和稀泥）。
- 缺口标注（防过度综合编造）。

## 反例（不该用 SYNTHESIS）
- 单一来源 → CO-STAR
- 需要批判性评价 → 加"评估"意图

## 环境适配
- 多材料建议 XML 分隔（Claude 解析可靠；其他模型用 Markdown 分隔）
- 引用编号与材料段一一对应（Verifiability 维）
