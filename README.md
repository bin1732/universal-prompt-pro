# 万能提示词系统

> 万能提示词系统。当用户要求生成/优化/评估/诊断/压缩/迁移提示词、system prompt、agent指令、判断提示词好坏、适配模型平台时使用。

## 功能特性

- **提示词生成**：根据需求一键生成高质量提示词
- **优化迭代**：诊断与优化现有提示词效果
- **压缩精简**：在保持效果的前提下精简提示词
- **多模型适配**：适配主流大模型平台特性
- **质量评估**：多维度评估提示词质量与效果
