**万能提示词系统** — 生成 / 优化 / 评估 / 诊断 / 压缩 / 迁移 一站式提示词工程工具

> 专业级提示词工程工具。提示词生成、优化迭代、质量评估、问题诊断、压缩精简、平台迁移、模型适配、长度控制——提示词相关的一切都能搞定。

## ✨ 特性

- ✍️ **智能生成** — 根据需求描述一键生成高质量提示词
- 🔧 **优化迭代** — 诊断现有提示词问题，精准优化提升效果
- 📊 **质量评估** — 多维度评分，量化提示词质量水平
- 🔬 **深度诊断** — 定位提示词不 work 的根本原因
- 📦 **压缩精简** — 在保持效果的前提下精简提示词长度
- 🔀 **平台迁移** — 不同平台 / 模型间的提示词适配迁移
- 🎯 **模型适配** — 针对 Claude / GPT / DeepSeek / Gemini / Kimi 等模型特性优化
- ⏱️ **最新实践** — 跟进提示词工程领域的最新方法与最佳实践

## 🧩 核心能力

| 能力 | 说明 |
|------|------|
| 生成提示词 | 从 0 到 1 创建符合场景的高质量提示词 |
| 优化提示词 | 针对已有提示词进行迭代优化，提升效果 |
| 评估评分 | 多维度量化评估提示词质量与潜力 |
| 诊断分析 | 找出提示词不 work 的原因并给出改进方案 |
| 压缩精简 | 缩短长度、精简表述，不降低效果 |
| 迁移适配 | 适配不同模型、不同平台的特性差异 |
| 长度控制 | 按目标长度精确控制提示词规模 |
| Agent指令 | 生成 / 优化 system prompt、agent 指令 |

## 🚀 快速开始

在支持 OpenClaw / Codex CLI / ChatGPT / Claude Code / DeepSeek / Gemini / Kimi 的环境中加载本技能后即可使用。

```
# 常见触发方式
- "帮我写一个产品文案写作的提示词"
- "优化一下我的system prompt"
- "评估一下这个提示词怎么样"
- "这个提示词不work，帮我诊断一下"
- "把这个提示词压缩到一半长度"
- "把Claude的提示词改成适配GPT的"
- "让提示词跟上最新实践"
```
